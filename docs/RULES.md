# Règles de Lamap

Lamap oppose deux joueurs pendant cinq manches.

## Cartes

Le jeu contient les cartes de 3 à 9 dans les quatre couleurs. Le 9 de pique est retiré. Chaque joueur reçoit cinq cartes.

## Une manche

1. Le joueur qui a la main pose une carte.
2. L’autre joueur doit suivre la couleur s’il la possède.
3. Si les deux cartes ont la même couleur, la valeur la plus forte gagne la manche.
4. Sinon, le joueur qui avait la main gagne la manche.
5. Le vainqueur prend la main pour la manche suivante.

Le vainqueur de la cinquième manche remporte la partie.

## Kora

Une victoire obtenue avec un 3 sur la dernière manche déclenche l’effet Kora. Deux ou trois manches finales consécutives remportées avec un 3 renforcent l’animation. Ces variantes restent strictement visuelles et sonores : le classement applique le même calcul qu’à toute autre victoire.

## Modes

- Classé : deux joueurs authentifiés, avec évolution Elo.
- Entraînement : IA facile, moyenne ou difficile, sans évolution Elo.
